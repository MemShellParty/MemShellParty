boot 服务内置 MCP Server，端点为 `/mcp`，协议为 Streamable HTTP。
部署后端点跟随当前地址，Jar 与 Docker 默认为 `http://127.0.0.1:8080/mcp`。

## 可用工具

| 工具 | 说明 |
| --- | --- |
| `memshell_capabilities` | 列出全部 server、shellTool、shellType、packer、探测方式、混淆参数与混淆范围 |
| `generate_memshell` | 返回内存马的 POST 请求计划（`endpoint` + `body`），不生成也不回传 payload；`body` 与 `POST /api/memshell/generate` 一致，支持 Godzilla、Behinder、AntSword、Suo5、Command 等 |
| `generate_probe_shell` | 返回探测马的 POST 请求计划（`endpoint` + `body`），不生成也不回传 payload；`body` 与 `POST /api/probe/generate` 一致，支持 DNSLog、ResponseBody、ResponseHeader、Sleep |

> 建议先调用 `memshell_capabilities` 获取合法参数，再调用生成工具拿到 `endpoint` 与 `body`。`body` 保存为文件后用 curl 或其他 HTTP 客户端 POST 到 `endpoint`，响应也写入文件，payload 不经过 MCP 上下文。没有 HTTP 工具的纯聊天客户端无法把 payload 留在上下文之外。

## 客户端配置

<Tabs items={["Claude Code", "Cursor", "VS Code", "Claude Desktop"]}>
  <Tab>
    ```bash
    claude mcp add --transport http memshell-party http://127.0.0.1:8080/mcp
    ```
  </Tab>
  <Tab>
    保存到 `.cursor/mcp.json`：

    ```json
    {
      "mcpServers": {
        "memshell-party": {
          "type": "streamableHttp",
          "url": "http://127.0.0.1:8080/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab>
    保存到 `.vscode/mcp.json`：

    ```json
    {
      "servers": {
        "memshell-party": {
          "type": "http",
          "url": "http://127.0.0.1:8080/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab>
    Claude Desktop 仅支持 stdio，需通过 mcp-remote 桥接（依赖 Node.js）。

    ```json
    {
      "mcpServers": {
        "memshell-party": {
          "command": "npx",
          "args": ["mcp-remote", "http://127.0.0.1:8080/mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>

保存配置后重启客户端生效。URL 替换为实际部署地址。

## 调用流程

1. 调用 `memshell_capabilities`，获取合法的 server、shellTool、shellType、packer 等取值。
2. 调用 `generate_memshell` 或 `generate_probe_shell`，拿到 `endpoint` 与 `body`。
3. 把 `body` 写入 `request.json`，再 POST 到 `endpoint` 并把响应写入文件：

   ```bash
   curl --data-binary @request.json -H 'Content-Type: application/json' -o memshell.json <endpoint>
   ```

4. 用 `jq` 只读取需要的字段，例如 `jq -r '.memShellResult.shellClassName, .packResult' memshell.json`。

endpoint 使用 MCP 客户端连接时的地址，所以 MCP 与 REST 必须经过同一个入口。反向代理要保留 `Host`，或转发 `X-Forwarded-Host`。入口是 HTTPS 时，还要转发 `X-Forwarded-Proto`。入口带子路径时，还要转发 `X-Forwarded-Prefix`。服务端设置 `server.forward-headers-strategy=framework` 后才会采用这些头。

示例指令：

```
先调用 memshell_capabilities 获取合法参数，再调用 generate_memshell 拿到 endpoint 与 body，然后把 body 保存为 request.json 并 POST 到 endpoint，最后只读取响应文件中的类名与 payload。
```
